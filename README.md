# Lumini

Academic management platform for schools: grade tracking, attendance, behavior reports, communications, and report card generation.

## Quick Start

```bash
pip install -r requirements.txt
cp .env.example .env   # configure SECRET_KEY, SENDGRID_API_KEY
python flask_app.py
```

Open http://localhost:5000
